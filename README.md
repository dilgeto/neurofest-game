# Animaciones NeuroFest
## Animaciones y juegos disponibles
- NeuroGame (modos: VS IA y Evaluar Red)
- Patrones de Izhikevich
- Sinapsis Excitatorias vs Inhibitorias
- Encoders
## Requerimientos
- Raylib
- CMake
- Makefile

## Cómo compilar
```bash
cmake -S . -B build
cmake --build build
```
Para compilar posteriormente solo hace falta el 2do comando.
